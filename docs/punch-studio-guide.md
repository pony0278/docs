# PUNCH STUDIO 使用指南

PUNCH STUDIO（`punch_studio.html`）是一個 **pose-by-pose 招式關鍵幀編輯器**：
用一條時間軸上的數個關鍵幀，逐幀擺出戰鬥動作，反求/微調出參數，再匯出給引擎。

> 對應資料格式契約見 [`docs/move-data-schema.md`](./move-data-schema.md)（v3）。

---

## 0. 心智模型（先懂這個）

一個招式 = **一條時間軸上的數個關鍵幀（key）**，每個 key 是一個「定格姿勢」（41 個關節參數）。
引擎/播放器在 key 之間補間，就成了動畫。

- 預設 5 個階段：`IDLE → ANTI(預備) → STRIKE(出招) → IMPACT(命中) → RECOVERY(收招)`
- 語意上等同格鬥遊戲的 **startup / active / recovery**（`IMPACT` 段＝命中判定段）
- 畫面 **左邊是 3D 角色舞台**，**右邊是控制面板**

## 1. 怎麼開（重要）

### 線上版（推薦，到處可用）
合併到 `main` 後會自動部署成 GitHub Pages：

> **https://pony0278.github.io/docs/**

手機 / 任何裝置開這個 https 網址即可，**AI 偵測也能用**，不用起本機伺服器。
（首次需做一次性設定，見本檔末「附錄：啟用 GitHub Pages」。）

### 本機版
```bash
# 在 punch_studio.html 所在資料夾(擇一)
python -m http.server          # 有 Python
npx serve                      # 有 Node
php -S localhost:8000          # 有 PHP
# 然後瀏覽器開 http://localhost:8000/punch_studio.html
```

> ⚠️ **不要直接雙擊檔案（`file://`）開** —— 那樣「🤖 AI 偵測」的模型會被瀏覽器擋下。
> 其他功能 `file://` 可用，但 AI 偵測一定要用本機 http 或上面的線上版。

舞台操作：**滑鼠拖曳＝轉鏡頭**、**滾輪＝縮放**。

## 2. 方式 A — 從預設 / 手動編排（最快上手）

1. 右側 `— 載入預設 —` 選一個招式範本（例：`左鉤 hook_l`、`★ 3連擊 combo`）。
2. 點上方 **phase tab**（或 timeline 上的 key）選一個要編輯的幀，例如 `STRIKE`。
3. 拉右側 **pose slider** 即時改姿勢：
   - **軀幹 ROOT**：`root_y` 旋身、`root_pz` 前撲、`squat` 蹲下
   - **雙手 ARM**：肩 / 肘 / `scale`（命中放大）
   - **雙腿 LEG**：髖 / 膝 / **`接觸鎖`**（0 平踩 / 1 墊腳 / 2 抬起）
4. 工具：
   - `L↔R 鏡像`：左右招互換
   - `複製 key…`：把別的 key 姿勢複製到目前 key
   - `填入站架`：回到站姿
5. 每個 key 都擺好後 → 見 [第 4 節](#4-播放與校時) 播放。

> 拖 slider 太慢時可勾 **🖐 直接拖動**，在 3D 畫面上直接抓關節節點拉。

---

## 3. 方式 B — 照參考圖逆向重製

「丟圖 → 對位 → 反求出參數」的流程，治旋身 / 景深 / 墊腳。

### 3-1 載入參考（圖 或 影片）
1. `📁 載入參考圖` 選一張該幀的分鏡 / 截圖。
2. 調 `透明度`；按 `對齊(拖曳/滾輪)` 把圖挪到跟角色重疊；必要時 `水平翻轉`。

> **參考影片**：也可改用 `📹 載入參考影片` —— 拖「影片 scrub」找到要的那一幀（或 `◀ 幀 / 幀 ▶` 微調），
> 不用先把影片切成截圖。對好後**存成視角時會自動把「目前這一幀」烘成該視角的參考圖**（之後切視角顯示的是這張靜態幀）。
> 很適合 GetAmped 那種「正面一段、側面一段」的錄影：正面影片 scrub → V1，側面影片 scrub → V2。

### 3-2 AI 自動放點（或手動）
3. 按 `🎯 點關節對位` 進入對位模式（鏡頭自動轉正面）。
4. 按 **`🤖 AI 偵測`** → MediaPipe 自動把 13 個關節目標圈放到圖上的關節。
   - 信心低的點會自動排除（變虛線）。
   - **準** → 下一步；**歪** → 手拖修；**L/R 反了** → 按 `L↔R 鏡像`；**抓不到** → 改全手動拖。
5. （手動）空心圈拖到參考圖對應關節；被遮擋的關節 **雙擊** 排除。

### 3-3 多視角（治深度：旋身 / 前後）
6. 對好正面後 → **`📸 存成視角`**（得到 V1）。
7. 按 **`🎥 側面`** → 載入側面參考圖 → `🤖 AI 偵測` 或手拖 → **`📸 存成視角`**（V2）。
8. 點 V1 / V2 chip 可來回切（**參考圖會跟著換**）；改完按 **`💾 更新`** 存回該視角。

### 3-4 反求
9. 按 **`▶ Solve 反求`** → 系統反推關節角度寫進「目前 key」。
   - readout 顯示「多視角(2)→ 深度可解」表示有用兩個視角三角測量。
10. 不滿意就拉 slider 微調（2D 讀不出的 twist 在這步補）。

### 3-5 墊腳 / 重心
11. 該幀若是踮腳 / 重心在某腳：拉該腿 `接觸鎖` ＝ `1 墊腳`，騰空腳 ＝ `2 抬起`
    → 身體會自動站到支撐腳上。

## 4. 播放與校時

1. **`▶ PLAY`** 跑完整一輪；`0.3×` 慢動作；`LOOP` 循環。
2. 下方 **SCRUB** 拉桿 = 凍結在任一補間幀觀察弧線。
3. 右側 **TIMING（frame）** 調每段幀數（ANTI / STRIKE / IMPACT / RECOVERY 的長短＝節奏）。
4. **LAG（鞭打延遲）** 調四肢相對軀幹的延遲，做出鞭打感（IMPACT 段不吃 lag，命中要齊）。
5. 上方 **timeline bar** 可直接拖 marker 改 key 的 timing；下方 key 列可點選 / 微調。

> 觀察小技巧：勾 `白模` 看剪影、`基準線` 看軸向。

---

## 4.5 打擊感試打（HIT FEEL）

動畫本身感覺不到「打擊感」—— 打擊感來自**命中那一刻的演出**。右側 **🥊 HIT FEEL** 群組會在
時間軸進入 **`impact` 段**時自動觸發（所以 3 連拳會有 3 次、跆拳道踢中也會觸發）：

- **沙包 dummy**：勾選 → 角色前方出現可打的沙包（打空氣 vs 打到東西，手感差很多）。用 `沙包距離 dist` 對齊到拳/腳落點。
- **命中停頓 hitstop**：命中瞬間凍結幾幀 —— **打擊感頭號功臣**，先從 0.08s 調起。
- **畫面震動 shake**：命中時鏡頭抖一下。
- **沙包擊退 knockback**：沙包被打退 + 壓扁回彈。
- **音效**：用 WebAudio 合成的「咚」（不需音檔；按 ▶ PLAY 才會解鎖音效）。

> 建議：按 ▶ PLAY、關掉 `0.3×` 用正常速度感受真實節奏；先把 hitstop / shake 調到你滿意。
> 這些是**預覽演出參數**，目前不影響匯出資料,但正是未來要寫進招式資料的「打擊感」欄位候選。

## 5. 存檔與匯出

| 按鈕 | 用途 |
|------|------|
| **`JSON`** | 推薦的保存格式（完整 timeline + 41 軸 + lag + 比例），對應 `move-data-schema.md` v3 |
| **`EXPORT → Godot`** | 貼進引擎用的文字格式 |
| **`📥 匯入參數`** | 把之前的 JSON / Godot 文字貼回來 |
| **`↶ UNDO / REDO ↷`** | 每步操作可回溯（另有自動存檔） |
| **`📷 擷取 contact sheet`** | 整輪 × 雙角度截成一張圖，給 AI / 自己審動作 |

---

## 一句話總結流程

> **載入預設或丟參考圖 → AI 偵測 / 手拖對位 →（多視角）Solve 反求 → 拉 slider 微調 + 設接觸鎖
> → 逐 key 做完 → 調 TIMING / LAG → PLAY 確認 → 匯出 JSON**

## 附錄：名詞速查

| 名詞 | 意思 |
|------|------|
| key / 幀 | 時間軸上的一個定格姿勢 |
| phase | 招式階段（IDLE/ANTI/STRIKE/IMPACT/RECOVERY） |
| 視角 (view) | 一組「鏡頭參數 + 2D 目標點 + 參考圖」，多視角用來三角測量解深度 |
| Solve 反求 | 由 2D 目標點反推出關節角度 |
| 接觸鎖 (contact) | 每隻腳與地面的接觸狀態：0 平踩 / 1 墊腳 / 2 抬起 |
| lag | 四肢相對軀幹的鞭打延遲 |

## 附錄：啟用 GitHub Pages（一次性設定）

部署 workflow 在 `.github/workflows/deploy-pages.yml`，但需要做三件事各一次：

1. **把 repo 改 public**：repo → **Settings → General → Danger Zone → Change visibility → Public**。
   （GitHub 免費方案的 Pages 只支援 public repo。工具本身沒有祕密；你載入的參考圖是瀏覽器本機讀取、不會上傳。）
2. **開 Pages 來源**：repo → **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。
3. **讓它跑一次**：把這個分支的 PR 合併到 `main`（或到 **Actions** 分頁手動 Run「Deploy PUNCH STUDIO to GitHub Pages」）。

完成後每次 `main` 上的 `punch_studio.html` 有更新，就會自動重新部署到
**https://pony0278.github.io/docs/** 。
